# 乐颜秀项目总览与进度

基线日期：2026-09-23。本文根据本地源码、包配置、Git 状态和既有验收记录整理；本次未连接云控制台核实实时线上状态。文中相对路径均从解压后的工作区根目录起算，代码表中特别注明从 app 起算。

## 产品与已确认规则

乐颜秀是面向中老年用户的图片/视频人脸融合与 AI 图片效果应用，当前主要工程为 React 网页 + Capacitor Android + Node/Hono API + 运营管理后台。模板含唱歌、跳舞、语录等；部分效果为固定算法，部分为生成式模型。

- Android 包名 `com.yibohuaxia.leyanxiu`；iPhone 目前是布局预览，没有 iOS 安装包。
- 正式用户不赠送制作次数，允许浏览，购买次数包后生成；历史闭测额度保留审计但不能当正式付费余额。
- 第一期支付为国内 Android 微信 APP 支付，不含自动续费；小程序支付、苹果内购、支付宝和 Google Play 不应被宣称已完成。
- 模板预览与实际提交供应商的源视频必须一致；素材上传成功不等于取得版权/肖像/音乐授权。
- 支付到账以服务端已验签通知或权威查单为准，不以客户端微信 SDK 回调为准。
- 保留已确认的项目办理口径：不把 ICP 经营许可证重新列为当然必办项。此为既有项目决策记录，非本次法律结论；如需重审适用规则，应另核实实际业务及现行要求。
