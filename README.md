## 脱敏与使用边界

- 密钥、真实环境配置、登录资料、个人/业务数据库、真实用户人像和签章身份材料不纳入。
- 文档中实际公司名称、联系方式、个人标识及已识别私密入口使用占位符；技术包名和公开依赖信息按用途保留。
- Office/PDF保留匿名正文，不保留扫描页、图片、修订、作者元数据；已单独审阅的项目截图使用遮挡副本。
- 含敏感内容的ZIP、安装包和部署包保存 `.sanitized.zip` 或其他明确脱敏副本。它们用于归档，不能直接当作安装包、生产部署包或原始验收证据；原文件hash/签名不适用于脱敏副本。
- 真实配置、用户数据和私人素材没有备份到GitHub。恢复开发时须另配本地环境；正式发布必须重新构建、签名和验收。
- 本次归档和批准上传清单不包含任何 `.git` 内部文件；原本地Git历史保留在原工作区/本地备份。
- 本次工作是文件归档与完整性验证，没有重新部署、发短信、执行支付或宣称App/小程序已上线。
