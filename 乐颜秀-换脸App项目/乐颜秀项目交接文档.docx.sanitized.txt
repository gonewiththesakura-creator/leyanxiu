一、项目概述
产品名称：乐颜秀（暂定） 一句话定位：一张照片，圆中老年用户一个明星梦——上传一张正脸照，即可把热门MV/视频中的主角换成自己，一键分享到微信/抖音。 目标客群：45~70岁中老年用户（女性为主），核心场景为广场舞群、家族群、老同学群的社交分享。 商业模式：免费次数裂变获客 + 会员订阅（月卡¥18 / 季卡¥45 / 年卡¥128）。 当前阶段：产品原型完成，核心生成能力（阿里云视频人脸融合API）已真实调通，具备路演和技术验证条件。
已验证的关键结论
个体工商户主体可开通阿里云全部所需能力（官方工单书面确认）。
单条15秒换脸视频生成成本约0.25元，生成耗时约10~15秒，体验达标。
输出视频自动带「视频由 AI 生成」水印，合规标识由云厂商兜底。
通过5组真人实测，已形成《模板选品规范》与《用户拍照引导》标准。

三、产品功能清单（原型已实现）
3.1 用户主流程（三步成片）
选模板：首页单列大卡片模板流（适老化设计），6个模板：难忘今宵（怀旧金曲）、舞动人生（广场舞）、旗袍风华、峥嵘岁月（军旅）、梨园名角（戏曲）、福寿满堂（全家福）。
传照片：拍照或相册上传，模拟人脸质量检测；内置3个示例头像供演示。
生成与分享：5步拟真进度动效 → 成片页 → 一键分享。
3.2 增长裂变体系
免费额度：新用户2次，localStorage记录。
分享得次数：抖音/快手/视频号/微信群/朋友圈5渠道，每平台每天限领1次。
平台定制文案：各平台自动标题+话题标签，全部带 #乐颜秀 产品tag。
防薅羊毛设计（原型已演示流程）：真实跳转校验 → 停留时长检测 → 回流验证（好友点击才发奖）→ 24小时复核到账、异常追回、设备指纹黑名单。
额度墙：次数用尽后按钮置灰，引导分享或开会员。
3.3 会员订阅页
三档定价 + 权益展示（无限次、4K无水印、专属模板、优先队列）。

四、技术架构
4.1 总体架构
微信小程序/App前端（React原型，待迁移uni-app）        │  POST /api/fusion {templateId, photoUrl}        ▼server/index.js（Hono，Node.js）        │  ① IP限流（每IP每分钟3次）② 内容安全前置机审（待接）        ▼server/providers/aliyun.js        │  通用模式 MergeVideoFace / 模板模式 MergeVideoModelFace        ▼阿里云 videoenhan（华东2·上海）→ 异步任务 → GetAsyncJobResult 轮询        │        ▼  成片URL（带AI水印）→ 存OSS → 返回前端
4.2 前端（/app）
React 18 + TypeScript + Vite + Tailwind + shadcn/ui。
原型换脸合成为浏览器端Canvas演示（src/lib/composite.ts），配置了 VITE_API_BASE 后自动切换真实API（src/lib/api.ts），服务不可达自动回退演示模式。
4.3 服务端接入层（/server）
已真实调通（2026-07-28/29实测），关键实现要点：
视频人脸融合能力属于 videoenhan（视频生产）产品，端点 videoenhan.cn-shanghai.aliyuncs.com，API版本 2020-03-20，Node官方SDK未收录，采用POP RPC签名直调（见 providers/aliyun.js）。
异步任务模式：提交后返回 RequestId 作为 JobId，GetAsyncJobResult 轮询，状态 PROCESS_SUCCESS 时 Data.Result（JSON字符串）内含 videoUrl（签名URL，约2小时过期，需及时转存自有OSS）。
关键参数：WatermarkType: "CN"（中文水印，合规必开）；Enhance: true（美颜增强，实测观感更好，建议默认开）。

《模板选品规范》四条铁律： 1. 光线第一：明亮均匀，夜景素材原则淘汰； 2. 单人正脸/微侧脸特写，人脸占画面1/4以上，偏侧≤30度； 3. 手部远离脸部：手在脸前挥动/遮挡超0.5秒的素材一票否决（遮挡重影是当前API能力边界）； 4. 模板分年龄段：给中老年用户推气质成熟型模板，年龄差越小效果越真。
已知短板与对策：手部遮挡脸部时可能出现融合重影（竞品自研XSeg遮挡模型无此问题）。对策链：选品规避（当前主手段）→ 已拟好阿里云工单询问遮挡感知能力 → 双供应商（腾讯云）对比 → 融资后自建inswapper+XSeg管线反超。

七、合规体系
7.1 四层审核防线（自动化设计）
上传时：内容安全-图片审核API前置机审（pass/review/block，block自动删除+提示+同设备3次违规封禁24h）；
生成后：成片过内容安全-视频审核；
存储期：OSS违规检测自动增量扫描+自动冻结（控制台配置即可）；
review档与申诉：简易人工后台复核。
7.2 上线前必须完成的合规动作
深度合成算法备案（网信办备案系统，审核20~40个工作日，需《算法安全自评估报告》——可直接引用阿里云官方审核机制作为佐证）+ 公安平台安全评估。
实名认证+人脸核身（防冒用他人照片），人脸照片属敏感个人信息，须单独同意+24小时自动删除承诺。
生成内容强制AI标识（阿里云输出已自带）+ 显著位置提示。
软著、ICP备案/许可证、隐私政策（专业律师起草）。

九、风险与注意事项
密钥安全：AccessKey曾在沟通中明文传输，建议本阶段结束后在RAM控制台轮换；转发源码包前删除 server/.env。
OSS公共读：正式版改私有+签名URL，防流量盗刷。
成片URL时效：API返回的videoUrl约2小时过期，服务端须即时转存自有OSS。
余额监控：按量付费，建议设置阿里云费用告警（如日超50元短信提醒）。
账号权限复核：官方文档提示人脸融合类能力”开通后需控制台提交权限申请”，当前已可调用，建议控制台确认无待办申请状态。
竞品差异：遮挡重影问题靠选品规避，不可向用户承诺”任意视频都能换”。
