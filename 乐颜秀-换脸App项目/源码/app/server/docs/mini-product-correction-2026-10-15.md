# 原 App 产品一致性纠偏与本地验收

日期：2026-10-15。目标仍为完成原乐颜秀小程序并正式收费运营。本轮结论是产品尚未完成，不再将三效果体验包当作完整交付；没有新的上传、云部署、付款、供应商生成、提审或正式发布。

## 已确认的根因

原始 React App 源码与素材保留在 canonical app 目录。`src/data/effects.ts` 有 17 个效果，`server/photo-effects.js` 有对应生成式或专用执行分支；视频有 4 个模板玩法。历史本地生成报告及成品能证明部分原实现曾运行，但不能替代当前平台/供应商验收。

小程序此前只有 3 项图片接到新制作管线。五栏目、17 张目录卡、4 段视频预览，以及目录/商品只读检查均不能证明原产品完整交付。接手验收应按用户实际旅程检查，而不是把目录恢复与接口通过当作完整产品通过。

## 原能力恢复已做与未做

已新增原 Seedream 13 个生成式效果的独立适配核心，复用原 ID/提示词、一次 POST、无自动 fallback 或失败重试。官方图像 API 确认支持 data URI，因此直接使用已验证字节，避免增加不必要的签名源图 URL 服务。仅保存真实合法 `x-request-id`，缺失时明确回执不完整，不能以本地摘要冒充供应商请求 ID。

该模块尚未加入生产包或接入 lifecycle/default provider，也未改变商品、白名单、公开协议和当前三效果范围。详细依据见 `original-seedream-adapter-2026-10-15.md`。原年龄变化、清晰修复、上色、高清放大四项专用执行器，以及四个视频模板，需要各自正确接入；不能用普通提示词冒充这些功能。

下一阶段必须将原能力复用到现有身份、权益预占、持久任务、审核、存储和失败处理，再完成逐效果真实交付与用户旅程验收。当前不具备“原产品完工”或正式提审结论，不向用户再次请求购买来代替这些缺口。
