## 2. 实际数据流与受托范围

1. 用户在微信选择一张压缩照片，在本机预览；明确授权后，经小程序云调用进入本方服务器。服务器核验身份、授权版本、有效期与预算，先保存上传意图，再写私有 OSS 原图。照片字节不放入业务 SQL 表或客户端持久任务记录。
2. 输入审核：本方创建独立私有临时对象，以短期签名 URL 供上海 Green 读取；审核前持久保存清理责任。只有绑定实际字节摘要、方向、服务、版本及官方回执的允许结果才能继续；未知、需复核或拦截结果不作为已通过。
3. 生成：服务器在再核授权和权益后，将照片字节编码为 data URI，连同固定效果参数发送百炼北京接入点。没有向模型附带 OpenID、手机号或支付订单。固定模型为 `qwen-image-2.0-2026-03-03`；不是把用户照片发布成公开输入链接。
4. 交付：取得服务方回执与生成图片后，在本方加可见“AI编辑”及机器可读标识；以最终标识字节做输出审核，再保存私有作品、登记归属并结算。审核结果与最终交付摘要绑定。未知请求保留原意图，不能通过重发生成试探状态。
5. 用户经授权取得最长60秒的作品链接；下载后本地副本由用户控制。删除、到期、撤回使新访问授权失效，后台对原图、作品和审核临时对象执行清理并保留未确认责任。

## 3. 保存、删除与权利处理

- **照片在线期：**现行候选策略对原图和结果分别设置24小时，从各自上传或制作任务建立时计算。到期/删除/撤回后停止签发新链接，已有作品链接最多60秒残余有效；审核临时链接最长120秒，仅供处理方读取。这不是两个“全部副本擦除”时限。
- **清理：**现有上传与生成清理表持久记录删除意图、精确对象键、重试及认证 HEAD 观察，并处理晚到写入。2026-10-12 桶配置只读报告确认：版本控制未启用、复制规则为空、桶级生命周期为空，三个受控前缀均没有可确认的自动过期或非当前版本清理规则；桶级 ACL 为 `public-read`，Public Access Block 未启用。因此清理责任仍在应用 worker 和供应商/备份合同，不能靠 OSS 自动配置推断。已验闭售015配置没有运行清理定时任务；内部商测接入制作时须同时启用、观察已有调度，不能把本次文档更新当作调度已开启。一次 `NoSuchKey` 只证明当时该键不存在，不能证明历史版本、备份或厂商副本永久消失。技术上暂不能删除的部分，应限制为必要存储和安全保护，不再次用于制作。
- **会话与业务记录：**登录24小时、支付临时会话10分钟是认证有效期，不是物理删除时点。订单、权益、授权及任务摘要按履约、退款、争议及实际法定义务的最短必要期间保留。现有 SQL 没有通用元数据 TTL，运营需用已有管理能力执行必要清理；不在本文新增30天、三年订单或一年邮件承诺。
- **法定例外：**相关网络日志按实际适用的网络安全要求保留不少于六个月，不能扩张为所有照片或操作记录。第56条要求影响评估报告及处理情况记录至少保存三年，适用于本评估及其必要记录，不是把图片保存三年。
- **权利入口：**原生页面提供作品删除及同意撤回；公开邮箱 `REDACTED_COMPANY_CONTACT_EMAIL` 受理查阅、复制、更正、删除、注销和争议。验证请求人与账户的合理关联，尽量使用已有会话和订单，不默认索取身份证；必要核验、供应商配合或法定保留要解释进展。邮箱实际值守与完整受理闭环尚无本轮演练证据。撤回不取消依法查询原订单或申请退款的权利；恢复备份后也须应用既有撤回/删除状态。
