# 小程序支付安全与上线门槛复核

日期：2026-09-30。范围：小程序虚拟支付源码、私有配置保护、现有云托管访问配置、SSL 官方支持请求、项目发布门槛。
结论：保持停止收费。本文是本轮工程复核，不是独立安全审计、法律意见或正式上线验收。

## 本轮修复与验证

`payments/virtual/runtime.js` 的 MySQL TLS 原来仅在 DEPLOY_ENV=production 时要求 CA，且未显式开启 mysql2 主机名校验。
现在所有通过 virtualMysqlOptions 建立的 MySQL 连接都要求 CA 文件，开启 rejectUnauthorized、verifyIdentity，并将最低 TLS 版本设为 1.2。
未提供 CA 或 CA 文件不存在时提前失败，不能通过改变环境标签回退到明文。连接地址必须与官方证书身份匹配，当前内网 IP 是否适用尚未实测。
更新 `.env.example` 说明，新增 TLS 配置回归测试。此改动只在本地，未部署新服务。

使用已有 Node 22.23.1 和系统已安装 FFmpeg：小程序五份定向测试 32/32 通过；服务端 154 个 JS 文件语法检查通过。
首次系统 Node 24 运行因 better-sqlite3 ABI 不匹配失败；切换 Node 22 后补充现有 FFMPEG_PATH，最终通过，未重装依赖。
新增测试验证缺失 CA 拒绝、证书文件缺失拒绝、mysql2 实际接收验证选项；没有真实 MySQL TLS 握手证据。
账本和主服务集成测试使用隔离 SQLite 与微信测试桩；不替代 MySQL 并发、死锁、故障恢复或真实资金验收。

未提交任何密钥、用户照片、订单数据或账号密码。未同意创建安灯服务相关角色，取消该弹窗后正常建单。
[官方角色策略](https://cloud.tencent.com/document/product/598/98539) 包含 resource=* 的跨服务访问、COS 读取及 tat:RunCommand 等权限；这不是本次 TLS 咨询必需的授权范围。
21:15:51 官方工程师确认微信云托管 MySQL 不支持开启 SSL 加密认证。21:17:21 已追问支持 TLS 的独立数据库私网接入、实例转换、费用和主机名方案。
当前选择原则为保留已有库和数据，优先评估官方支持的私网托管 MySQL/TDSQL-C，取得网络和价格证据后再决策；未新购、未迁移。
[普通 CloudBase Run 官方文档](https://cloud.tencent.com/document/product/1243/49231)描述同 VPC 访问 MySQL，但不能据此断定当前微信云托管环境可直接复用，需平台确认。
不得用 REQUIRE NONE、rejectUnauthorized=false 或开启公网绕过。

## 合规发布条件

本轮用支付专项配置执行现有 release-check，实际返回 publicLaunchAllowed=false。
该配置不是完整生产配置，因此“缺配置”不能等同于公司未备案、材料未办或线上设置缺失；用户提供的小程序已备案证据保留，未改写为未备案。
已有代码明确列出的实名适配、内容安全、持久化和管理员缺口仍须逐项证据核实；不会填 verified=true 冒充完成。

依据实际图片/视频功能判断适用范围，不能仅以“AI换脸”名称或小程序备案通过推定全部义务完成。

- 按[深度合成管理规定](https://www.cac.gov.cn/2022-12/11/c_1672221949354811.htm)核查人脸编辑告知与被编辑人单独同意、实际服务涉及的身份核验、内容治理、日志及适用的备案/安全评估要求。服务提供者和供应商职责分别核实。
- 按[生成合成内容标识办法](https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm)核查显式/隐式标识与下载导出保留；保留项目对 GB 45438-2025 的实测证据门槛。
- [人脸识别技术应用安全管理办法](https://www.cac.gov.cn/2025-03/21/c_1744174262156096.htm)是否适用须结合是否实际进行识别身份等技术活动判断，不把所有照片处理自动等同于人脸识别。
- 隐私指引、敏感信息处理、第三方清单、保存期限、供应商删除、用户删除/撤回通道与实际链路一致；版权、肖像、模板及音乐授权分别留证。
- 最终价格、适用能力、限额、有效期、服务中断和退款处理须与平台商品及购买页面一致。云端生成无限用、永久云算力和自动续费均未获准发布。
- Android/iOS 微信真机支付、取消、重复通知、退款、换设备仍待验收；真实资金操作必须先明确账号和金额上限。
