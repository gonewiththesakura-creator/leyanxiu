# App 账号闭测：数据清理与功能限制实施方案

状态：保留的原实施方案。账号清理、持久日志和账号专用门禁后续已实现并部署，真实验证及未完成项以《App手机号账号闭测交付-2026-10-09.md》为准；下表仍包含未完成的每日加密异机备份等目标，不能把整份方案视作全部实现。

适用范围：阿里云独立 App 的受邀手机号登录测试；支付保持 `closed_test`，不开放媒体制作。客服和隐私邮箱已由用户确认：`REDACTED_COMPANY_CONTACT_EMAIL`。

## 为什么不能直接发布现有协议草稿

短信签名和模板已经通过，但目前代码中的验证码有效期、限流窗口、设备恢复有效期并不等于记录物理清理期限。账号库缺少统一定时清理；关闭付费模型和设置零制作额度也没有封闭全部上传接口。需要先补齐并验收这些实际行为，再将确定期限写入对外政策。

## 拟采用的清理规则

| 数据 | 已有行为 | 实施目标 |
|---|---|---|
| 验证码校验值 | 五分钟有效，成功/失败超限后不可重用；表内仍保存派生值 | 使用、退出或注销后清空校验值；过期值由每五分钟扫描清空。保留防刷字段，不因验证码失效就删除计数。 |
| 防刷索引与发送计数 | 发新码时才清理超过二十四小时的 OTP 行 | 每五分钟扫描清理超过二十四小时的行，最晚再经过一个扫描周期处理；服务停机或作业异常必须报告，不能隐瞒超期。注销不得重置手机号、IP、设备及全局日额度。 |
| 已失效的会话明细 | 到期/撤销影响资格，但元数据没有统一清理 | 撤销即清令牌摘要；过期或撤销七天后清理会话明细。需要留存的安全事件另入最小化安全日志，不靠长期保留凭据完成审计。 |
| 设备登录映射 | 最长三十天，退出解除映射并更新版本 | 空映射按扫描删除；自然失效七天后清理。删除后旧会话仍须失效。涉及旧财务身份别名的 `billing_devices` 不纳入这次批量清理。 |
| 同意与撤回状态 | 有版本、时间、证据；尚无按时间清理 | 账号存续期保留每类每版本的最新状态，尤其不得删除最新撤回而让旧同意重新有效。注销后的证据与安全记录按其类别核定，不把普通缓存期限套到审计或财务记录。 |
| 网络运行、安全事件与登录安全审计 | 有部分应用记录；示例关闭普通 Nginx 访问日志；真实日志策略未全面验证 | 单独配置最小必要的网络安全日志并至少保留六个月；到期后按类别清理。有争议、事故或依法延长要求时限制用途并另记期限。日志不得含明文验证码、令牌、密钥、完整手机号或完整查询字符串；不能因单文件容量上限提前淘汰仍需保留的记录。 |
| 日常备份 | 已有一次一致性恢复演练，尚无自动轮替和异机加密 | 拟每日一致性加密备份，滚动保留十四天；新备份恢复验证通过后才淘汰旧备份。安全日志另按至少六个月保存，不套用十四天备份期限。保留足够覆盖备份窗口的注销清单，恢复后重新执行注销与会话/OTP 失效，再开放服务。 |

日志期限依据：[现行《网络安全法》第二十三条](https://www.gjbmj.gov.cn/n1/2026/0421/c409088-40705863.html)。本方案不采用“所有安全日志只留三十天”的建议，也不把关闭某份 Nginx 访问日志等同于可以不保留必要的网络安全日志。具体字段、存储容量与运维职责仍须随实现验收；这不是已通过全面合规审查的结论。

拟新增独立账号清理模块：启动时执行一次，此后每五分钟执行。账库变更走现有事务锁；身份及会话状态通过 `compliance-store` 存储接口修改，不直接篡改 SQLite 整体快照。现有 `retention.js` 主要处理报告/媒体，不能当作账号清理已完成的证据。初次执行前做只读计数与一致性备份，验证匹配范围后再允许删除；不触碰订单、退款、账本或账号主键，不轮换 `ACCOUNT_OTP_SECRET`。

## 账号测试的功能范围

拟增加 `APP_ACCOUNT_ONLY` 服务端门禁，在首批业务路由注册前生效；按清晰列出的请求方法和路径放行。允许设备认证、邀请码校验、手机号验证码、账号/套餐状态只读、同意管理、退出、注销、健康状态和公开模板浏览。

媒体上传、模型/文案调用、制作任务、私有作品访问、历史任务恢复、订单支付及相关后台写入应在读取媒体、创建任务或联系供应商前拒绝。保留 `/templates/*`、`/effects/*` 等已公开内置素材，不能因模板浏览而放开私有对象接口。客户端同步隐藏或停用拍照、选图、文件上传、制作、文案和购买入口；仅禁用“开始制作”按钮不够。

这是一项待实现的账号测试限制，不代表 App 正式产品取消媒体和付费功能。完整功能开放时要另行完善照片/人脸处理告知、供应商信息、授权和删除证据。

## 完成标准

1. 没有新请求时也会清理到期记录；模拟时钟验证边界，过期验证码不能重放。
2. 清理及注销都不重置二十四小时防刷预算；退出/删映射后旧会话不能恢复。
3. 清理保留最新撤回状态；普通账号清理不影响财务记录或既有手机号索引。
4. 恢复旧备份不会让已注销账号重新可用；日志保存期与备份轮替分别验证。
5. 直接调用媒体/模型/支付 API 被门禁拒绝，供应商调用数为零；公共模板、手机号登录、退出和注销仍正常。
6. 将验证后的真实期限写入用户政策，同步服务端和 APK 的协议链接及版本。基础隐私入口目前使用 `2026-09-05`，账号条款使用 `account-v1`，二者须分别核对，不能只改网页标题。
