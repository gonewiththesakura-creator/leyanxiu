# 微信云托管部署指南

> 目标：零自有服务器。服务跑在微信云托管（容器），用户上传走云存储，
> 任务台账走云数据库，内容审核用微信官方接口。域名/SSL/ICP 备案域名均不需要。

## 一键部署（前置：小程序已开通云开发）

1. 小程序后台 →「云开发」→ 开通**云托管**，创建一个服务（名字如 `leyanxiu-api`）
2. 上传本目录代码（控制台「代码包上传」或用微信开发者工具的「云托管」面板）：
   - 根目录的 `Dockerfile` 会被自动识别，云端构建镜像（Node20 + ffmpeg + Python/PIL）
   - 端口填 `80`（容器内 `PORT` 由平台注入，Hono 已读 `process.env.PORT`）
3. 在「服务配置 → 环境变量」里配置（等同本地 `.env`，**不要提交 .env 到代码包**）：

| 变量 | 值 |
|---|---|
| `PROVIDER` | `aliyun` |
| `ALIYUN_ACCESS_KEY_ID` / `ALIYUN_ACCESS_KEY_SECRET` | RAM 子账号 AK（需要 viapi + OSS 权限） |
| `TENCENT_SECRET_ID` / `TENCENT_SECRET_KEY` | 腾讯云 AK（减龄/变老用） |
| `OSS_BUCKET` / `OSS_REGION` | `leyanxiu-face-2026` / `oss-cn-shanghai` |
| `TPL_*` / `PTPL_*` / `MTBG_*` | 各模板配置（同本地 .env） |
| `TCB_ENV_ID` | **自动注入，无需手填**（存在即启用云数据库台账） |

4. 云数据库建集合：`tasks`（空集合即可，无需索引）
5. 部署完成后平台会分配默认公网地址 `https://<服务名>-<环境>.app.tcloudbase.com`，
   小程序端用 `wx.cloud.callContainer` 或该地址直接调用（走云调用免域名白名单）

## 镜像里有什么

- `node:20-bookworm-slim` + `ffmpeg`（maskedmerge 合成）+ `python3` + `PIL`（证件照）
- 工作目录 `/tmp/leyanxiu`（容器临时盘，重启清空——所有持久化都在 OSS/云数据库）

## 本地与容器行为差异（代码已自动适配）

| 项 | Windows 本地 | 云托管容器 |
|---|---|---|
| ffmpeg | `C:\leyanxiu-repair\ffmpeg.exe` | 系统 `ffmpeg`（apt 装的） |
| 工作目录 | `C:\leyanxiu-repair` | `/tmp/leyanxiu` |
| 任务台账 | `tasks.json` 文件 | 云数据库 `tasks` 集合（检测 `TCB_ENV_ID`） |
| Python | 系统 PATH `python` | 系统 `python3`/PIL（apt 装的 `python3-pil`） |

## 运维要点

- 实例数：开发期「最小实例 0」省钱（有冷启动 2~5 秒），上线后改「最小实例 1」
- 计费：按 CPU/内存实际用量，小流量 ≈ 几元~几十元/月
- 日志：云托管控制台「日志」面板实时看（服务端 console 输出直通）
- 回滚：每次部署生成一个版本，控制台一键回滚
