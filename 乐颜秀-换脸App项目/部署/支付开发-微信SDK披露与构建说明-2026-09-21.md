# 微信支付 SDK 披露与构建说明

## 接入范围

- Android 集成腾讯微信 OpenSDK `com.tencent.mm.opensdk:wechat-sdk-android:6.8.40`，仅用于打开微信支付收银台和接收返回结果。
- 由深圳市腾讯计算机系统有限公司提供；隐私政策与开发文档须在正式隐私清单中列出并经公司确认。官方说明：https://open.weixin.qq.com/ 、https://pay.wechatpay.cn/doc/v3/merchant/4013289321 。
- SDK 在用户同意隐私政策后进入购买页时才实例化，用于检查微信安装状态。实际调起付款仅在用户点击购买后进行。
- SDK 使用微信安装状态、应用标识及支付订单参数（商户号、预支付标识、随机串、时间戳、签名）；具体 SDK 自身收集范围应以腾讯对应版本隐私政策为准，公司上线前需核对并披露。
- App 不采集微信支付密码、银行卡号，不保存 API 私钥、APIv3 密钥，不以本地 SDK 成功回调发放制作次数。到账完全以服务器验签/查单为准。

## 构建与验证

- 构建前设置 `WECHAT_APP_ID` 为微信开放平台已认证移动应用的真实 AppID（非密钥）。留空时购买入口明确不可付款。
- 包名为 `com.yibohuaxia.leyanxiu`。开放平台绑定的应用签名必须与实装 APK 一致；debug 签名不可冒充正式公司签名。
- `WXPayEntryActivity` 固定在包名的 `.wxapi` 路径，无 intent-filter，支持 Android 13+ 返回流程。
- 已通过 Java 编译；没有使用正式商户资金验证，不代表微信认证/签约/签名绑定已通过。
- 正式收费仍需可恢复的用户账号、确认退款规则、签名包真机付款/取消/断网/进程被杀/退款验收。当前设备身份不可跨设备自动恢复，购买页已明确提示，普通用户收费应保持关闭。
