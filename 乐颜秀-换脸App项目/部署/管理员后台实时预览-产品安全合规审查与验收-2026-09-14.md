# 乐颜秀管理员后台实时预览：产品、安全、合规审查与验收

版本：2026-09-14  
适用范围：乐颜秀运营后台的模板、图片效果、功能分区、配色与客户端实时预览  
审查依据：当前仓库静态代码、既有上线整改材料、最小权限与发布可追溯原则  
说明：本文是产品与工程上线闸门，不替代律师、应用商店、网信或其他主管部门的正式审核结论。

## 1. 审查结论

| 闸门 | 结论 | 允许范围 |
| --- | --- | --- |
| 实时预览方案 | 有条件通过 | 可进入本机或内网受控测试；完成本文 A 类验收后方可交付运营使用 |
| 后台公开生产部署 | **NO-GO** | 在生产级认证、持久化、素材权属和审计证据闭环前，不得暴露公网管理入口 |

第一性原则：预览的目标是回答“配置发布后用户将看到什么”，不是在后台再次运行一次真实业务。任何需要用户身份、真人照片、供应商模型、生成任务、计费或作品落库的行为，都不属于预览。

## 2. 产品边界与状态模型

后台必须让运营人员始终看清五个不同状态，不能只显示一个笼统的“已修改”：

| 状态 | 含义 | 可否影响线上 |
| --- | --- | --- |
| 正在编辑 / 未应用 | 编辑器内临时值，仅在内存中预览 | 否 |
| 已应用 / 未保存 | 已进入浏览器本地草稿，尚未写入服务端 | 否 |
| 草稿 `rN` / 待发布 | 已通过服务端校验并以修订号保存 | 否 |
| 草稿 `rN` / 与线上一致 | 当前查看的是草稿来源，但内容与线上完全一致 | 否 |
| 线上 `vN` / 已同步 | 已由有权角色正式发布 | 是 |

标准流程：

`编辑器临时值 -> 应用到本地草稿 -> 服务端校验并保存 rN -> 审核人比较草稿与线上版本 -> 发布 vN -> 客户端 /api/catalog 获取新版本`

必须支持：

- 草稿与线上版本一键切换预览，且线上预览不得混入未保存内容。
- 模板、图片效果、分区、配色和全局开关的差异摘要。
- 编辑未应用、应用未保存、草稿待发布、线上已同步的视觉状态。
- 刷新、退出、关闭编辑器或切换页面前，对未保存内容进行明确确认。
- 两个管理员并发操作时，以 `expectedRevision` 拦截旧修订写入；收到 `REVISION_CONFLICT` 后必须刷新并重新审阅，禁止静默覆盖。

生产环境必须执行双人原则：草稿提交者不得批准自己的发布。Owner 虽具备全部技术权限，也不能绕过独立复核。生产账号必须实名分配，禁止多人共享同一个 `admin` 账号。

静态代码检查表明，服务端路由已按角色限制草稿保存、发布、回滚、治理和紧急暂停；生产或启用 `ADMIN_REQUIRE_DUAL_APPROVAL=true` 时会拒绝同一账号自编自发。最终验收仍需用四个独立测试账号逐项验证 200/403 响应矩阵。

## 4. 实时预览的无副作用约束

### 4.1 允许行为

- 对当前目录配置做纯前端投影、过滤、排序和主题渲染。
- 加载已入库的同域静态图片或视频；这属于只读素材请求，不是“零网络请求”。
- 调用带登录态和 CSRF 的只读目录校验接口；校验不得保存、发布或写审计业务数据。
- 在预览容器内切换推荐、视频玩法、精选和百变图片页面。
- 展示素材 `loading / ready / error` 状态、隐藏内容提示和维护公告。

### 4.2 禁止行为

- 打开相册、相机、麦克风、通讯录或原生权限。
- 上传用户照片、调用人脸检测、模型供应商或内容生成 API。
- 创建或恢复生成任务、写入作品、消费次数、下单、支付或退款。
- 读取真实用户身份、作品、订单、举报或生物识别数据。
- 因预览点击而触发埋点计费、供应商调用或对外 webhook。
- 加载运营输入的任意外域 URL。

当前预览组件采用受控客户端视图，图片玩法传入 `networkEnabled=false`，所有“制作/生成”动作由拦截回调替换，并在界面提示“预览已拦截上传、生成和扣次”。素材 URL 只接受 `/` 开头的同域绝对路径，拒绝 `//`、`..`、反斜杠、换行和非白名单扩展名。该设计边界合理，但必须用网络拦截测试证明点击全流程仅出现同域静态 `GET` 与只读校验请求。

## 5. 草稿、发布、回滚与审计

当前服务端具备以下控制：

- 公共 `/api/catalog` 只返回已发布且启用的模板、分区和图片效果。
- 草稿保存要求 `owner/operator + CSRF + expectedRevision`。
- 发布要求 `owner/reviewer + CSRF + expectedRevision + 4-120 字发布说明`。
- 无变化发布被拒绝；生产环境同一账号提交与批准被拒绝。
- 回滚会生成一个新的发布版本，而不是改写历史版本。
- 草稿保存、发布和回滚写入操作者、时间、版本及目录哈希。
- 旧数据启动迁移只为当前草稿、当前线上版本和对应当前发布记录补建基线；缺少历史证据的其他版本标记为 `legacy-unsealed`，界面禁用回滚，接口返回 409 `UNSEALED_RELEASE`。
- 紧急暂停仅 Owner 可执行，并通过新的发布版本关闭生成开关。

仍需整改：

- 当前管理配置与审计使用单机 JSON；即使采用临时文件加原子重命名，也不等同于数据库事务、跨实例锁、备份和灾备。
- 操作审计存在数量上限，且不是防篡改日志；生产需进入持久数据库/集中审计平台并设置保留期、导出和告警。
- 回滚操作需在数据库迁移时加入“预期当前发布版本”或事务锁，防止与同时发生的发布产生竞态。

## 6. 素材路径、哈希与权属完整性

已实现的技术校验：

- 目录只允许同域绝对路径，并限制图片为 JPG/JPEG/PNG/WebP、视频为 MP4/WebM。
- 保存前检查素材文件确实存在于受控公开目录。
- 规范化目录生成 SHA-256 `catalogHash`。
- 每个被引用素材生成 SHA-256 清单；发布时若文件自草稿保存后被替换，返回 `ASSET_CHANGED` 并阻断发布。
- 回滚时重新核对历史素材清单；二进制已变化的历史版本不能直接恢复。
- 客户端请求当前线上目录引用的素材时，服务端按已发布清单复核文件；缺失、改变或未封印均返回 503，不再继续提供被替换的字节。
- 旧数据迁移已区分“原始 JSON 摘要失配”和“校验规则升级后的规范化差异”：前者拒绝启动，后者更新摘要并写入 `catalog.integrity_migrated` 审计。

硬性剩余风险：

1. 当前版本能够为旧数据建立一次迁移基线，但历史上没有素材指纹的旧发布无法追溯当时字节，已按失败关闭原则禁止直接回滚。
2. 文件存在和哈希一致只证明“是同一个文件”，不证明拥有商用版权、音乐权、肖像权或字体许可。
3. 当前版权就绪检查只确认存在授权资产编号，尚未证明目录中的每个路径/哈希都逐项映射到授权台账。
4. 后台不得直接开放任意素材上传。新增素材需经过隔离区、文件头/MIME/尺寸/时长校验、恶意文件检测、转码、人工内容审核、权属凭证、到期日、适用渠道和复核人记录后再入库。
5. 请求时哈希校验是当前的防篡改补偿控制；生产仍应采用内容寻址或不可变版本路径，禁止在同一路径覆盖线上文件，以避免大文件高频校验带来的性能与可用性风险。

生产发布的素材证据至少应记录：`assetId、路径、SHA-256、原始来源、权利人、授权范围、渠道、地域、期限、音乐/字体/肖像附加权利、审核人、审核时间、下架状态`。

## 7. 安全与隐私审查

已存在的基础控制包括：scrypt 密码哈希、签名会话、`HttpOnly`、`SameSite=Strict`、生产 `Secure` Cookie、CSRF 校验、来源校验、登录限速、角色校验、安全响应头和生产 HSTS。

公开生产部署前的 P0 阻断项：

- 管理员 MFA 尚未实现；会话撤销与登录限速仍在进程内存中，重启或多实例后不能保持一致。
- 管理员配置仓库、工作流与审计必须迁移到有事务、备份、访问审计和最小权限账号的数据库。
- 至少配置两名具名管理员，并验证双人发布；禁用本地明文密码模式和默认账号。
- 管理后台必须置于 HTTPS、受控域名和网络访问策略后；建议增加 VPN/零信任、IP 条件访问或堡垒机。
- 任何曾在聊天、截图、文档或测试脚本中暴露的云账号口令、密钥和管理员密码必须立即轮换，不得进入仓库或构建产物。
- CSP 目前允许一般页面从 `https:` 加载图片、媒体和发起连接。预览层虽已做同域过滤，生产仍建议将外联域名缩小为经审核的精确白名单，并通过浏览器网络测试验证。
- 必须完成备份恢复演练、告警通知链路、事故响应联系人和紧急暂停后的恢复审批流程。

实时预览不得使用或缓存真人用户素材；测试只使用公司自有、已授权或合成素材。若未来增加“用用户作品预览”，必须作为新功能重新进行个人信息保护影响评估，而不能沿用本方案的无数据预览结论。

## 8. 可访问性与设备标注

- 服务端颜色发布闸门要求文字与背景、文字与卡片的对比度均不低于 4.5:1。
- 设备与版本切换应使用可键盘操作的按钮组，并暴露 `aria-pressed`；页面切换应保持完整的 `tab / tabpanel` 语义。
- 加载、校验、隐藏、素材失败和副作用拦截状态必须通过 `role=status/alert` 或等效方式被辅助技术感知，不能只靠颜色。
- 所有图标按钮必须有可读名称；焦点顺序、焦点可见样式、Escape 关闭和焦点返回需通过键盘验收。
- 如果编辑器和预览同时可交互，编辑器不得错误声明为排斥外部交互的 `aria-modal=true`；应把两者放入同一工作台焦点范围，或让预览成为真正只读区域。
- 素材地址变化时必须重置 `loading/error/ready` 状态，防止沿用上一个素材的成功状态。
- 不同视口下不得遮挡编辑字段、保存按钮、预览导航或错误信息；文字不得溢出控件。
- Android 标注表示当前客户端布局预览；iPhone 必须明确标注“模拟”。两者均不构成原生权限、解码器、音频策略、系统字体、无障碍或商店审核通过的证据。

## 9. 发布前验收清单

### A. 实时预览交付闸门

- [ ] A01：模板名称、封面、动态预览、排序、启用状态和配色修改在 150 ms 内反映到预览，无明显布局跳动。
- [ ] A02：编辑未应用、应用未保存、草稿待发布、草稿与线上一致、线上已同步五种状态显示准确。

## 11. 本次实现与验证记录

验证时间：2026-09-14（Asia/Shanghai）  
验证环境：本机隔离测试数据、Mock 生成渠道、`http://127.0.0.1:8790/admin`
