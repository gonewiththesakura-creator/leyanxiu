# 备份验证

打包过程使用随附恢复工具，对逻辑路径、分卷SHA-256、每个唯一文件对象SHA-256和字节数执行了完整校验，结果记录在 `verification.json`。每个分卷实际大小严格小于100 MiB。恢复工具另外通过成功、损坏、路径穿越、路径冲突和不覆盖等27项独立合成检查。

源文件与脱敏副本分开保存；任何验收、部署与安装结论仍须以原工程重新验证。`summary.json`记录归档规模，`manifest.json.gz`记录完整还原映射，`excluded.json.gz`记录排除原因。

最终选中的 49,651 个唯一文件对象均已纳入凭据扫描集合，未覆盖对象为 0；已提交扫描的归档解码文本对象累计 5,967 个。Gitleaks 主轮实际处理文本累计 488,487,074 字节，该数包含被替换对象及重复的归档解码文本，不是最终备份的唯一字节总量。扫描集合覆盖不代表对所有二进制做过 OCR 或完整语义审查。
